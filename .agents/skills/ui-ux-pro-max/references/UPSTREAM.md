## Excluded

- The donor `SKILL.md`, templates, quick reference, and pro rules
- Tests, fixtures, validators, refresh tooling, and upstream catalog snapshots
- The npm/Bun CLI, its installer/updater/uninstaller, and package dependencies
- The six additional skills generated by the upstream Codex installer
- Browser automation, external APIs, global configuration, and persistence

## Static admission findings

The admitted runtime imports only Python standard-library and local modules. No
network, socket, subprocess, shell, dynamic-import, `eval`, or `exec` path was
found. Normal searches read local CSV files and print output.

The donor runtime also exposes persistence flags that can create or overwrite
files. This trial's project-authored launcher rejects those flags before the
donor CLI runs, its instructions prohibit invoking that CLI directly, and
`python3 -B` prevents Python bytecode cache writes.

## Licence and version caution

The donor root `LICENSE` and `cli/package.json` declare MIT, but
`cli/README.md` says `CC-BY-NC-4.0`. The `v2.15.0` tag also contains
`cli/package.json` version `2.5.0`. Because these upstream statements conflict,
this copy is for a local, uncommitted evaluation only. Clarify the licence and
version provenance before committing, redistributing, or adopting it for
commercial use. This note is an engineering boundary, not legal advice.
